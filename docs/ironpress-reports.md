# Ironpress HTML reports

Settings → General → **Use new HTML PDF reports (Ironpress)** selects the engine
for Comparative Reports and Traffic Analysis. The preference is local, persistent,
and **off by default**. Turning it off restores the existing React PDF exports,
including their current theme and layout. Existing PDF templates are unchanged.

When enabled, export uses Ironpress 1.7.0 inside Rust/Tauri. It requires the desktop
app; browser exports display an actionable error instead of switching engines.
There is no print dialog, WebView capture, JavaScript execution or external process.

## Implementation

- `src/lib/appPreferences.ts`: `htmlPdfReports` in the existing preference store.
- `src/components/configmenu.tsx`: accessible General switch and explanation.
- `src/lib/htmlReportTemplates.ts`: standalone escaped HTML, editorial covers,
  observed insights, independent request/byte scales, chronological summaries,
  diagnostics, ranking appendices and source availability. Uses the export palette.
- `src/components/comparativeReportsWorkspace.tsx`: new engine branch using the
  existing immutable snapshot and export appearance; legacy branch retained.
- `src/components/trafficAnalysisWorkspace.tsx`: new engine branch using the same
  collected report, selection, volume queries and peak analysis; legacy retained.
- `src-tauri/src/traffic_pdf.rs`: `save_html_report_pdf`, blocking conversion off the
  async executor, A4 output and embedded existing 400/600 report fonts. Delegates
  the generated bytes to `save_traffic_pdf` without an intermediate write/read.
- `src-tauri/src/lib.rs`: command registration.
- `src-tauri/Cargo.toml` and `src-tauri/Cargo.lock`: exact Ironpress 1.7.0 dependency,
  without its remote feature. No app version change.
- Proxy Workspace: experimental print import/button removed; original Re-check
  button restored. `src/components/htmlPrintProof.tsx` removed.

HTML is capped at 4 MiB; generated PDFs are capped at 32 MiB and checked for their
PDF signature. Existing filename allowlists, app-cache location and create-new
write semantics apply. Sanitization remains enabled. No document resource root
or base directory is authorized, and remote fetching is disabled at dependency
feature level. Fonts are embedded from compile-time assets, not user paths.
All data text/attributes are HTML escaped; CSS colors accept only resolved hex
palette values. Charts use static CSS bars with numeric labels and explicit scales.

## Interpretation and limits

These reports describe available records, not security verdicts. Overlapping
comparison periods are not additive. Zero baselines do not produce percentage
changes. Unavailable byte coverage suppresses byte comparisons; partial fields
can still undercount. HTTP rankings in Traffic Analysis are subsets, so they do
not support a complete inferred error total. Original common-interval results
are retained as a separate comparison appendix when present.

Charts show up to 12 entries, ranking tables up to 20, comparison period detail
up to 64 periods and provenance up to 100 sources. Labels longer than 600
characters are marked as shortened. Display limits are disclosed in the report;
comparative CSV retains full snapshot detail and Traffic Analysis retains full
capture access. Time charts combine supplied buckets by timestamp without
interpolating events inside an original bucket.

Ironpress implements its own CSS layout; it is not Chromium and exact browser
parity is not promised. Native conversion already underway cannot be interrupted;
unmount/cancellation in Traffic Analysis suppresses subsequent viewer/toast actions,
but the PDF may still be saved. Output size is checked after rendering.

## Manual acceptance (not executed during implementation)

1. Start the updated Tauri desktop app. Confirm the switch defaults to off and both
   export buttons still produce the current legacy PDFs.
2. Turn the switch on, close/reopen Settings and restart the app to check persistence.
3. Export Comparative Reports and Traffic Analysis. Confirm the PDF is saved in the
   existing app cache and opens without a print dialog. Check light and dark themes,
   page backgrounds, fonts, page numbers, table headers, long labels and page breaks.
4. Compare printed totals, ranges, time zones and ranking values with the same
   snapshot/selection. Include empty results, missing byte/status fields, a zero
   comparison baseline, overlapping periods and a common-interval comparison.
5. Turn the switch off and export again: current legacy designs should return.
6. In a browser, enable the switch and export: expect the desktop requirement message.
7. Confirm Proxy Workspace contains Re-check proxies and no Test Print to PDF button.

No build, test suite or PDF render was run during implementation. Compilation,
actual Ironpress rendering and visual acceptance remain to be performed in Tauri.
